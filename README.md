# Missione Puccini – Open Day 2026

Dieci web app didattiche indipendenti per l’Open Day della Scuola Media G. Puccini (12 dicembre 2026).

## Pubblicazione su GitHub Pages

1. Crea un repository pubblico, per esempio `missione-puccini-open-day`.
2. Carica **il contenuto** di questa cartella nella radice del repository (non il file ZIP).
3. Apri **Settings → Pages**.
4. In **Build and deployment**, scegli **Deploy from a branch**, poi **main** e **/(root)**; salva.
5. Attendi la pubblicazione e apri `https://TUO-UTENTE.github.io/missione-puccini-open-day/`.

La pagina iniziale `index.html` collega le dieci applicazioni nelle rispettive sottocartelle. Per aprire una singola attività, aggiungi il nome della cartella al link, ad esempio `/arte/`.

## Struttura

- `index.html`: menu principale
- `italiano/`, `storia_geografia/`, `matematica/`, `scienze/`, `tecnologia/`, `arte/`, `musica/`, `inglese/`, `francese/`, `motorie/`: ciascuna con il proprio `index.html`
- `.nojekyll`: evita elaborazioni non necessarie da parte di Jekyll

Non richiede account ai visitatori e non prevede l'inserimento di dati personali. Prima dell'evento, verifica le app sui browser e sulle LIM utilizzate.
